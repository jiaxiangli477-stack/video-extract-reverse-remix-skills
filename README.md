# 视频提取、提示词反推与二创

这是两个可配合使用的Codex Skill，以及中文简介和可复制反推提示词示例。当前为私有备份仓库。

|Skill|中文名称|什么时候用|主要输出|
|---|---|---|---|
|[yt-dlp-extract](yt-dlp-extract.zip)|跨平台视频、音频与字幕提取|给视频链接，需要本地素材/音频/字幕|媒体文件、规格与完整解码结果|
|[vibe-video-reverse](vibe-video-reverse.zip)|视频提示词反推与二创|直接发视频或给链接，需要提示词、复现或二创|分镜时序、导演/编程提示词、源码和成片对照|

## 使用顺序

直接发送本地视频时，跳过下载。提供链接时，先观察实际内容，按需提取，再反推提示词；要求做出视频时继续制作和验收。

示例指令：

> 用视频反推Skill分析这条视频。输出完整、可复制的导演提示词和编程提示词，再按与原片相同的时长复刻；保留原声用于本地对照。

> 参考这个视频的方法二创：保留其叙事节奏和视觉机制，换成我的主题和内容，先做关键样片再输出完整成片。

## 安装与依赖

下载并解压上表对应的Skill ZIP，将解出的同名目录放入当前Codex的Skill发现目录，保留内部文件结构。两项配合时一起安装。也可下载[完整源码包](video-extract-reverse-remix-skills.zip)，其中保留 `skills/`、`examples/` 和文档目录。复用已有Python3、Node.js、FFmpeg/FFprobe和yt-dlp；视频制作另用宿主已有的渲染工具，不自动付费、安装或发布。

脚本已去除必须依赖本机工具绝对路径的默认值；文档中的D盘任务目录只是原用户的工作目录示例，可按目标项目规则更换。浏览器操作使用目标宿主提供的浏览器能力。
